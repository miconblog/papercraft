## 배경

전술 대형 프리셋은 **출발점**이다. `IDE-003`이 규격을 정할 때부터 "프리셋은
출발점이고, 사용자는 적용한 뒤 자유롭게 옮긴다"고 적었고, 스키마도 그 전제로
만들어졌다 — 슬롯마다 이동 범위(`regionId`)가 있고 `movableSlots`에는 "에디터가
드래그 대상을 고를 때 쓴다"는 주석이 달려 있다.

그런데 옮기는 조작 자체가 없었다. `IDE-006`이 "마커를 손으로 옮기는 조작까지는
할 일에 없다 — 옮기고 싶으면 다른 대형을 고르는 방식으로만 가능하다. 드래그
배치가 필요해지면 별도 이슈로 뺀다"고 남겼다(2026-09-05). 사용자가 요청해
그 이슈를 연다.

대형이 네 개뿐이라 프리셋만으로는 "이 선수만 조금 옆으로" 같은 것이 안 된다.
`IDE-010`이 두 팀을 필드 전체에 섞어 세우면서 배치가 게임의 재미를 직접
좌우하게 됐고, 그만큼 손으로 만지고 싶은 요구도 커졌다.

## 할 일

- [x] 미리보기에서 마커를 끌어 옮기기 (마우스 · 터치 · 펜)
- [x] 갈 수 있는 범위를 도안이 정한 영역으로 제한
- [x] 옮긴 좌표를 저장하고 인쇄물에 반영
- [x] 키보드로도 옮기기 — 드래그만 두면 키보드 사용자가 배치를 못 바꾼다
- [x] 누르기(입력으로 이동)와 끌기를 구분
- [x] 손으로 옮기면 대형 버튼의 눌린 표시를 푼다

## 수용 기준

- [x] 프리셋을 적용한 뒤에도 마커를 끌어 원하는 자리로 옮길 수 있다
- [x] 옮긴 좌표가 브라우저에 저장되고 새로고침해도 남는다
- [x] 옮긴 좌표가 인쇄물에 그대로 나온다
- [x] 도안이 정한 영역 밖으로는 나가지 않는다 — 끌어도 경계에 붙는다
- [x] 마커가 종이 밖으로 비어져 나가지 않는다
- [x] 화살표 키로도 옮길 수 있다(Shift로 크게)
- [x] 미리보기를 눌러 해당 입력으로 이동하는 기존 조작이 그대로 동작한다
- [ ] ⚠︎ 터치 기기에서 손가락으로 끌린다 — 포인터 이벤트 하나로 마우스·터치·펜을
      함께 받게 짰고 `touch-action: none`으로 브라우저 제스처를 막았지만,
      **실기 확인은 못 했다**(이 환경에 터치 기기가 없다)

## 결정 기록

- 2026-09-05 · **경계 규칙을 순수 함수 한 곳에 뒀다**
  ([`src/lib/customization/movement.ts`](../src/lib/customization/movement.ts)).
  화면이 제 나름대로 좌표를 자르면 저장 검증(`validateCustomization`)과 어긋날
  수 있고, 그러면 사용자가 만든 값이 **조용히 버려진다** — 저장소가 도안과 안
  맞는 값을 버리도록 되어 있기 때문이다(`storage.ts`). "어디로 끌든 저장 검증을
  통과하는 좌표만 낸다"를 테스트로 고정했다.
- 2026-09-05 · 영역 판정은 `containsPoint`와 같게 **마커 중심**으로 하되, 파트
  경계에 대해서만 마커 반크기를 더 물렸다. 중심이 종이 안이어도 마커가 가장자리에
  걸치면 인쇄물에서 반쪽이 난다.
- 2026-09-05 · **누른 자리와 마커 중심의 차이를 기억한다.** 그러지 않으면 마커를
  잡는 순간 중심이 손끝으로 튀어, 가장자리를 잡았을 때 배치가 흐트러진다.
- 2026-09-05 · 끌지 않고 누르기만 한 것(4px 미만)은 클릭으로 돌려, 미리보기의
  마커를 눌러 그 입력으로 가는 `IDE-006`의 조작을 드래그가 잡아먹지 않게 했다.
- 2026-09-05 · **손으로 옮기면 대형 버튼의 눌린 표시를 푼다.** 4-4-2를 적용한 뒤
  한 명이라도 옮기면 그것은 더 이상 4-4-2가 아니다 — 표시를 남겨 두면 화면이
  거짓말을 한다. 좌표 자체는 `customization.positions`에 있고 버튼 표시는 별도
  상태라(`IDE-006`) 둘을 분리해 다룰 수 있었다.
- 2026-09-05 · 드래그는 **미리보기가 편집용일 때만** 켠다(`onMoveSlot`을 준
  경우). 인쇄 화면의 미리보기(`PrintPreview`)는 보기 전용이라 마커가 움직이면 안
  된다 — 거기서 옮기면 무엇이 인쇄될지와 화면이 어긋난다.
- 2026-09-05 · 실제 브라우저(CDP)로 확인했다 — 끌어서 옮기기(화면 이동량과 mm
  변환이 정확히 비례), 필드 밖으로 끌면 경계에 붙기, 화살표 키 이동,
  `localStorage` 반영, 대형 표시 해제.
