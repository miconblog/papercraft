## 배경

축구 게임판에서 선수는 도안 위에 놓이는 별개의 층이다. 필드는 고정이지만 선수는
스타일도 위치도 사용자가 고른다. 그래서 필드 도안(`IDE-004`)과 분리해 만든다.

두 가지가 필요하다(2026-09-03 확정):

- **마커 스타일 두 벌** — ① 원 + 등번호 ② 선수 일러스트 + 등번호. 사용자가 고른다.
  ①은 사용자가 직접 만든 판의 방식이고, ②는 옛 인쇄본의 방식이다
- **전술 대형 프리셋** — 4-4-2, 3-5-2 같은 실제 축구 포메이션대로 11명을 배치한다.
  프리셋은 출발점이고 여기서 자유롭게 옮길 수 있다(`IDE-006`)

한 팀은 **골키퍼 포함 11명**, 양 팀 22명이다. 사용자가 만든 판 사진에는 골키퍼가
빠져 있었지만 정식 구성은 11명이다.

일러스트는 옛 인쇄본을 복제하지 않고 직접 만든다.
