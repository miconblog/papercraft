## 배경

축구 게임판에서 선수는 도안 위에 놓이는 별개의 층이다. 필드는 고정이지만 선수는
스타일도 위치도 사용자가 고른다. 그래서 필드 도안(`IDE-004`)과 분리해 만든다.

두 가지가 필요하다(2026-09-03 확정):

- **마커 스타일 두 벌** — ① 원 + 등번호 ② 선수 일러스트 + 등번호. 사용자가 고른다.
  ①은 사용자가 직접 만든 판의 방식이고, ②는 옛 인쇄본의 방식이다
- **전술 대형 프리셋** — 4-4-2, 3-5-2 같은 실제 축구 포메이션대로 11명을 배치한다.
  프리셋은 출발점이고 여기서 자유롭게 옮길 수 있다(`IDE-006`)

한 팀은 **골키퍼 포함 11명**, 양 팀 22명이다. 사용자가 만든 판 사진에는 골키퍼가
빠져 있었지만 정식 구성은 11명이다.

일러스트는 옛 인쇄본을 복제하지 않고 직접 만든다.

## 할 일

- [ ] 원형 마커 세트 작도 — 원 + 등번호, 팀 색 적용 가능하게, 골키퍼는 구분되게
- [ ] 일러스트 마커 세트 제작 — 스타일과 벌 수를 먼저 정한다(포지션별로 다른 포즈 / 몇 가지 포즈를 돌려 쓰기 / 전원 동일). 작업량이 여기서 갈린다
- [ ] 두 세트가 같은 슬롯에 교체 가능하도록 기준점·크기 규격을 맞춘다
- [ ] 등번호 가독성 확인 — 일러스트 위에 얹었을 때, 그리고 축소 배율에서
- [ ] 전술 대형 프리셋 좌표 데이터 작성 — 최소 4-4-2 · 3-5-2 · 4-3-3 · 4-2-3-1
- [ ] 각 프리셋의 기본 등번호 배정 (GK 1번 등 통념을 따르되 사용자가 바꿀 수 있다)
- [ ] 프리셋 좌표를 양 팀 진영에 대칭으로 적용하는 방식 정의
- [ ] 선수끼리 겹치거나 필드 밖으로 나가지 않는지 프리셋 전부 확인
- [ ] 흑백 출력에서 두 팀이 구분되는지 확인 (색만으로 구분하면 안 된다)

## 수용 기준

- [ ] 원형·일러스트 두 마커 세트가 모두 있고 서로 바꿔 끼워도 배치가 어긋나지 않는다
- [ ] 한 팀 11명(골키퍼 포함), 양 팀 22명이 도안에 배치된다
- [ ] 전술 대형 프리셋이 4종 이상 있고 각각 실제 포메이션에 맞는 배치다
- [ ] 어떤 프리셋을 골라도 선수가 겹치거나 필드를 벗어나지 않는다
- [ ] 흑백으로 출력해도 양 팀과 골키퍼가 구분된다
- [ ] 옛 인쇄본의 선수 일러스트를 복제하지 않았음이 문서로 확인된다
