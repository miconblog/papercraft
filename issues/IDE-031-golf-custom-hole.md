## 배경

사용자가 청했다(2026-09-15) — "커스텀으로 홀을 직접 구성할수있게 해줘."

어떻게 구성할지를 물었고, **판 위에서 끌어 그리기**를 골랐다(값을 골라 조립하는
쪽이 아니라). 장수는 **한 장**이다 — 값을 바꿔 여러 번 뽑으면 서로 다른 홀이
여러 장 된다.

## 규격에서 처음 밟는 것

**점 슬롯(`points`)** — 판 위에서 사람이 끌어 놓는 좌표의 목록이다.

값의 생김새는 `outline`(IDE-019)과 같다. 다른 것은 **무엇이 값을 만드는가**다.
윤곽은 사진에서 계산돼 나오고 사람은 손대지 않지만, 점은 사람이 하나씩 끈다.
그래서 이쪽에는 손잡이의 생김새(`handle`)가 있고 개수를 사람이 늘리고 줄인다.

마커 슬롯과도 다르다. 마커는 슬롯 하나에 점 하나이고 값(등번호)을 함께 그리지만,
점 슬롯은 슬롯 하나에 점 여럿이고 **그려지는 것은 점이 아니라 그 점들에서 나온
그림**이다. 배치가 `control`뿐인 것도 그래서다.

곁가지로 `text` 슬롯에 `control` 배치를 열었다. 홀 이름은 글자로 찍히지만 그
자리가 값에 따라 움직인다 — 카드가 사용자가 끄는 자리에 앉으므로 좌표를 도안에
미리 적을 수 없고, 판을 그리는 렌더러가 카드와 함께 그린다.

## 무엇을 끌 수 있나

| 슬롯             | 개수 | 뜻                                          |
| ---------------- | ---- | ------------------------------------------- |
| `custom-path`    | 2~5  | 첫 점이 티, 마지막 점이 그린. 가운데가 굽이 |
| `custom-bunkers` | 0~6  | 벙커                                        |
| `custom-ponds`   | 0~3  | 연못                                        |
| `custom-card`    | 1    | 홀 정보 카드의 왼쪽 위 모서리               |

칸에 적는 값은 넷이다 — 홀 번호(1~~18) · 홀 이름 · 파(3~~5) · 페어웨이 폭.
**거리는 적지 않는다.** 길 길이에서 나온다(`yardsForLength`) — 길을 늘리면 야드가
따라 늘어야 두 값이 어긋나지 않는다.

## 상자가 규칙을 대신한다

값이 사람 손에서 나온다. "여기까지"를 검증으로 막으면 끌다 말고 오류를 보게
되므로, **손잡이가 갈 수 있는 자리를 상자로 미리 좁혔다.**

- 길목 — 코스 영역에서 가장 넓은 페어웨이의 반폭(30mm)만큼 안쪽. 어느 점을
  어디로 끌어도 페어웨이가 O.B. 선을 넘지 않는다.
- 벙커·연못 — 코스 안쪽 14mm. 나머지는 렌더러가 마저 붙든다(반지름만큼 더
  밀려날 수 있다).
- 카드 — 카드 크기(52×52)만큼 안쪽.

## 수용 기준

- [x] 나만의 홀 한 장이 홀 판 묶음의 끝에 붙는다(셀렉트 맨 아래)
- [x] 길목·벙커·연못·카드를 판 위에서 끌어 옮긴다
- [x] 화살표 키로도 옮긴다(Shift로 다섯 배)
- [x] 개수는 폼에서 늘리고 줄인다 — 자리는 폼에 숫자로 내지 않는다
- [x] 어떤 값이 와도 판 하나는 나온다(빈 값이면 기본 홀)
- [x] 가장 넓은 페어웨이로 상자 끝까지 끌어도 길이 O.B. 선을 넘지 않는다
- [x] 해저드를 판 끝까지 끌어도 코스 안에 남는다
- [x] 카드는 어디로 끌어도 판 안에 들어간다
- [x] 거리가 길 길이에서 나온다
- [x] 기본값으로 그린 정적 파일을 커밋한다 — 값이 오기 전에도 판을 보여 준다
- [ ] ⚠︎ 종이 실측 — 내가 만든 홀이 실제로 칠 만한가(너무 좁거나 긴 홀이 나오는지)

## 남은 물음

- **그린 크기와 홀 자리**는 고르지 못한다. 고를 것이 많으면 짓기가 일이 되어
  일부러 뺐다. 써 보고 필요하면 연다.
- **개울**은 커스텀에 없다. 띠를 끄는 조작이 점 끌기와 다르고(폭과 방향이 함께
  필요하다) 연못으로 대신할 수 있다.
- 홀을 여러 장 만들고 싶다는 요구가 오면 **파트 여러 장**이 다음 걸음이다.
  지금은 값을 바꿔 여러 번 뽑는다.
