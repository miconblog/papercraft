## 배경

사이트의 핵심 상호작용이다. 방문자가 도안의 정해진 슬롯 — 축구 게임판이면 선수
등번호, 팀명, 팀 색 — 을 채우고 결과를 화면에서 바로 확인한다.

슬롯 타입은 `IDE-003`에서 정의되므로 에디터는 게임마다 새로 만들지 않는다. 스키마를
읽어 폼을 생성하는 방식이어야 게임이 늘어도 에디터는 하나로 유지된다.

## 할 일

- [ ] 슬롯 타입별 입력 컴포넌트 구현 (텍스트 · 숫자 · 색상 · 선택)
- [ ] 스키마를 읽어 폼을 자동 생성하는 렌더러
- [ ] 도안 미리보기 — 입력이 바뀌면 즉시 반영
- [ ] 미리보기의 슬롯을 눌러 해당 입력으로 이동
- [ ] 입력 검증과 오류 표시 (글자 수 초과, 범위 밖 숫자)
- [ ] 초기화 · 기본값 되돌리기
- [ ] 새로고침에도 입력이 남도록 로컬 저장

## 수용 기준

- [ ] 축구 게임판의 등번호 22개, 팀명 2개, 팀 색 2개를 모두 편집할 수 있다
- [ ] 입력 변경이 미리보기에 반영된다
- [ ] 새로고침해도 입력값이 유지된다
- [ ] 에디터 코드에 특정 게임 이름이 하드코딩되어 있지 않다
