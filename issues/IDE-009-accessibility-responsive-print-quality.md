## 배경

인쇄가 목적인 사이트라도 고르고 채우는 과정은 전부 화면에서 일어난다. 모바일에서
등번호 22개를 입력하는 경험, 키보드만으로 완주하는 경험이 여기서 갈린다.

출력물 자체의 품질도 함께 본다 — 흑백 프린터나 잉크 절약 모드에서 양 팀이 구분되지
않으면 게임이 성립하지 않는다.

## 할 일

- [ ] 모바일·태블릿 레이아웃 정리 — 특히 에디터의 폼과 미리보기 배치
- [ ] 키보드만으로 전체 흐름 완주 확인, 포커스 표시 정비
- [ ] 스크린리더 라벨 — 어떤 슬롯을 편집 중인지 전달
- [ ] 색상 대비 검사 — 사용자가 고른 팀 색이 대비를 깨뜨릴 수 있다
- [ ] 도안·미리보기 로딩 성능 점검
- [ ] 흑백 출력과 잉크 절약 모드에서 결과물 가독성 재확인

## 수용 기준

- [ ] 360px 폭에서 에디터와 내보내기를 끝까지 수행할 수 있다
- [ ] 마우스 없이 키보드만으로 커스터마이즈부터 내보내기까지 완주된다
- [ ] UI 텍스트가 WCAG AA 대비 기준을 충족한다
- [ ] 흑백 출력에서도 양 팀이 구분된다
