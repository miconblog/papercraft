## 배경

사용자가 물었다(2026-09-09). **"어드민 세션이 있으면 이벤트 로그가 안 찍혀야
하는 거 아니야?"**

안 찍히지 않았다. 제외는 오로지 경로로만 판단하고(`isExcludedPath`), 관리자
세션은 수집에 전혀 관여하지 않는다.

**그리고 관여할 수도 없었다.** 인증 쿠키가 `path: '/admin'` 으로 잠겨 있어
브라우저가 `/admin` 아래에만 보낸다 — 홈도, 게임 페이지도, 페이지뷰를 받는
`/api/analytics/event` 도 그 밖이다. 수집 쪽에서는 관리자가 로그인했는지 알
방법이 아예 없었다.

앞서 IP 제외를 논의할 때(2026-09-09) IP 가 자주 바뀌어 애매하다고 한 그 문제의
답이기도 하다. **로그인이 제외 표시를 심을 자연스러운 시점이다.**

## 인증 쿠키를 넓히지 않는다

`path` 를 `/` 로 바꾸면 쿠키 하나로 끝나지만 둘을 잃는다.

1. **인증 쿠키가 사이트의 모든 요청에 딸려 다닌다.** 좁게 잡아 둔 것은 실수가
   아니라 최소 권한이다.
2. **세션이 끝나면 제외도 함께 끝난다.** 제외는 인증보다 오래 가야 한다.

그래서 `dc_nocount` 를 따로 심는다(2026-09-09 사용자 결정).

| 쿠키         | 경로     | 수명 | 무엇인가                     |
| ------------ | -------- | ---- | ---------------------------- |
| `dc_admin`   | `/admin` | 90일 | 서명한 인증 쿠키             |
| `dc_nocount` | `/`      | 1년  | "나는 세지 마라" — 서명 없음 |

**서명하지 않는다.** 비밀이 아니기 때문이다 — 값이 새어도 할 수 있는 일이 자기를
통계에서 빼는 것뿐이고, 남의 수치를 부풀리지는 못한다.

## 인증은 오래 간다

12시간이었다. **브라우저를 껐다 켤 때마다 다시 로그인하는 것이 귀찮다**는 사용자
지적으로 90일로 늘렸다(2026-09-09). 여는 것이 집계 숫자뿐이고, 비밀번호를 바꾸면
이미 나간 쿠키가 전부 무효가 되므로 길게 두어도 잃을 것이 적다.

## 끄는 자리는 로그아웃 하나뿐이다

사용자가 그렇게 정했다(2026-09-09). 그래서 **로그아웃을 새로 만들어야 했다** —
`session.ts` 의 첫 주석이 "비밀번호를 바꾸면 되니 로그아웃을 따로 만들 필요가
없다"고 적어 둔 자리다. 이제는 필요하다.

둘을 **함께** 지운다. 하나만 지우면 로그인은 풀렸는데 통계에서는 계속 빠지거나,
그 반대가 된다. 지울 때는 심을 때 쓴 경로를 그대로 줘야 한다 — `/admin` 에 심은
것을 `/` 로 지우려 들면 **지워지지 않고 그대로 남는다.**

## 할 일

- [x] `session.ts` — `NOCOUNT_COOKIE` · `noCountCookie()` · `expiredCookie()` ·
      `hasNoCountCookie()`. 쿠키 이름은 통째로 견준다 — `includes('dc_nocount=')`
      로 보면 `xdc_nocount=` 같은 남의 쿠키에 걸린다
- [x] 인증 TTL 12시간 → 90일
- [x] 로그인이 두 쿠키를 함께 심는다
- [x] 로그아웃 서버 액션 — 둘을 경로까지 맞춰 지우고 홈으로 보낸다
- [x] `record.ts` — 쿠키가 있으면 기록하지 않는다(`reason: 'opted-out'`).
      **경로보다 먼저** 본다. 이 판단에는 경로가 필요 없다
- [x] 대시보드에 로그아웃 단추와 안내 한 줄 — 빼면 왜 내 방문이 안 잡히는지
      나중에 스스로 헷갈린다
- [x] 테스트 14개 — 쿠키 경로·이름 겹침·지우는 쿠키(`session`) · 로그인·로그아웃
      (`actions`) · 페이지뷰와 다운로드 모두 안 나가는지(`record`)
- [x] 문서 — `docs/analytics.md`
- [x] 실물 확인 — 사용자가 배포본에서 확인했다(2026-09-09). 다시 로그인한 뒤
      헤더를 보려면 `/admin` 밖을 열어야 하는데, **그 시각 이후 `events` 가
      한 줄도 안 늘었다**

## 수용 기준

- [x] 로그인한 브라우저는 홈·게임 페이지를 열어도 이벤트가 안 남는다
- [x] PDF 다운로드도 안 남는다 — 서버가 직접 세는 쪽이라 더 중요하다
- [x] 로그아웃하면 두 쿠키가 함께 지워져 다시 세어진다
- [x] 인증 쿠키는 여전히 `/admin` 안에만 머문다
- [x] 브라우저를 껐다 켜도 로그인이 유지된다 — 90일
- [x] 이름이 겹치는 남의 쿠키(`xdc_nocount`)에 걸리지 않는다
- [x] 배포본에서 확인 — 위와 같다

  넓히면 인증 쿠키가 모든 요청에 실리고, 세션이 끝나면 제외도 끝난다.
- **2026-09-09 — 인증은 90일**(사용자 지적). 껐다 켤 때마다 다시 로그인하는 것이

## 안 한 것

- **경로 제외(`excluded.ts`)를 걷어내는 것.** 겹쳐 보이지만 막는 것이 다르다 —
  로그인하지 않고 `/admin/login` 을 열었을 때는 쿠키가 없다.
