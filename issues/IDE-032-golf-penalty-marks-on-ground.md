## 배경

사용자가 **한 라운드 쳐 보고** 둘을 청했다(2026-09-15).

> 게임을 해보니 깃대는 필요 없을것 같아. 다만 땅에 따라서 벌타와 이전자리로
> 되돌아가는 표시가 땅모양에 같이 표기되면 설명서를 왔다갔다 하지 않아도 될것
> 같거든.

둘 다 **놀아 봐야 아는 것**이었다. `IDE-030`에 ⚠︎로 남겨 두었던 항목("깃대가
실제로 서는가")이 그중 하나다.

## 1. 처분을 땅 위에 적는다

| 땅            | 판에 적히는 말                 |
| ------------- | ------------------------------ |
| 모래(벙커)    | `+1타`                         |
| 물(연못·개울) | `+1타` · `앞자리에서 다시`     |
| O.B. 선       | `O.B. +1타 · 친 자리에서 다시` |

문구는 `scoring.ts`의 `PENALTY` 한 곳에 있다. **규칙문과 판이 같은 표를 읽는다**
— 한쪽만 고치면 종이와 설명이 어긋나고, 그 어긋남은 치는 도중에야 드러난다.

말이 짧은 것은 자리가 좁아서이기도 하지만 치는 도중에 읽는 글이라서다. 한 번에
눈에 들어오지 않으면 결국 설명서를 편다.

### 글자에 자리를 내준 세 곳

- **모래알** — 안쪽 절반을 비우고 테두리 쪽에만 흩는다.
- **물결** — 글자 자리(위아래 6mm)를 건너뛴다. 두 줄짜리 글의 아랫줄까지
  덮어야 해서 3.5mm였던 여유를 늘렸다.
- **나무** — O.B. 문구가 앉는 아래 두 모서리에 심지 않는다. 글자가 나무보다
  나중에 그려져 가려지지는 않지만, 연한 잎 위의 회색 글자는 흐려서 읽히지
  않는다.

**들어갈 때만 적는다.** 폭이 모자라면 두 줄 중 아랫줄을 버리고, 그래도 모자라면
통째로 뺀다 — 글자가 도형보다 크면 아무 말도 안 하느니만 못하다.

## 2. 깃대와 공을 뺀다

처음에는 A자로 세우는 종이 텐트 두 벌이 공과 한 장에 있었다. 쳐 보니 홀이
어디인지는 **판에 그린 깃발**로 충분했고, 세워 둔 종이는 공에 밀려 넘어지기만
했다.

- 파트가 조립물(`buildable`)에서 오림용 부속(`cutout`)이 되었다 — 접을 것이 없다.
- 종이가 210×148 → 100×100으로 작아졌고, 공이 열둘에서 열여섯으로 늘었다.
- 파트 id가 `flag-and-ball` → `balls`, 제목이 "깃대와 공" → "공"이다.
- 규칙문의 「깃대 세우기」 절이 「공 만들기」로 바뀌었다.
- **판 위의 깃발 그림은 남는다** — 멀리서 홀이 어디인지 알리는 일은 그림이 한다.

이어서 공도 뺐다(같은 날 — "공도 필요없어").

- 부속이 **하나도 없는 첫 게임**이 되었다. 인쇄물은 홀 판 열아홉 장과 기록표뿐이고
  오릴 것도 접을 것도 없다.
- 공은 준비물로 돌렸다 — 집에 있는 작고 납작한 것, 두꺼운 종이를 오린 원판,
  동전, 작은 단추 무엇이든 된다. 축구 게임판과 같은 처분이다.
- 지름(`BALL_DIAMETER_MM` 12mm)은 치수에 남는다. 인쇄물은 아니지만 **홀 원이
  이보다 커야** "닿아 멈추면 들어간 것"이 성립한다.
- 준비물에서 가위도 빠졌다 — 오릴 것이 없다.
- 인쇄 화면은 **고를 것이 없는 묶음의 단추를 내지 않는다.** 부속이 없는데
  '부속만'을 누르면 아무것도 고르지 않은 채가 되어 인쇄가 막힌다.

## 수용 기준

- [x] 모래·물·O.B.에 처분이 적힌다
- [x] 규칙문과 판이 같은 표(`PENALTY`)를 읽는다
- [x] 글자가 모래알·물결·나무에 가리지 않는다
- [x] 가장 작은 벙커에도 `+1타`가 들어간다
- [x] 열여덟 판 모두에 O.B. 처분이 적힌다
- [x] 깃대가 도안·규칙문·부속에서 빠졌다(판 위 깃발 그림은 남는다)
- [x] 공도 빠졌다 — 부속이 하나도 없고, 준비물이 대신할 것을 일러 준다
- [x] 홀 원이 준비물 공(12mm)보다 크다
- [x] 인쇄 화면이 빈 묶음('부속만')의 단추를 내지 않는다
- [ ] ⚠︎ 종이 실측 — 배율 100%에서 `앞자리에서 다시`(2.3mm)가 읽히는가
- [ ] ⚠︎ 쳐 보기 — 판만 보고 벌타를 처리할 수 있는가(설명서를 펴지 않는가)

## 남은 물음

- **개울의 처분**은 띠 한가운데 한 번만 적는다. 개울이 길어 양 끝에서는 멀지만,
  같은 문장을 여러 번 적으면 판이 수다스러워진다. 쳐 보고 정한다.
- 러프에는 아무것도 적지 않았다 — 벌타가 없기 때문이다. "여기는 벌타 없음"을
  적어야 할지는 놀아 보고 안다.
