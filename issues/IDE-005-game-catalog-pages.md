## 배경

방문자가 어떤 종이 게임이 있는지 보고 고르는 입구다. 지금은 축구 게임판 하나뿐이지만
목적이 "종이로 할 수 있는 보드게임 전부"이므로 구조는 처음부터 여러 개를 전제한다.

## 할 일

- [ ] 게임 목록 페이지 — 썸네일 · 제목 · 인원 · 지원 용지
- [ ] 게임 상세 페이지 — 소개 · 준비물 · 게임 방법 · 도안 미리보기 · 만들기 진입
- [ ] 메타데이터에서 페이지가 생성되도록 연결 (게임 추가 시 페이지 코드를 손대지 않게)
