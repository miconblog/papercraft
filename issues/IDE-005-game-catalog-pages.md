## 배경

방문자가 어떤 종이 게임이 있는지 보고 고르는 입구다. 지금은 축구 게임판 하나뿐이지만
목적이 "종이로 할 수 있는 보드게임 전부"이므로 구조는 처음부터 여러 개를 전제한다.

## 할 일

- [x] 게임 목록 페이지 — 썸네일 · 제목 · 인원 · 지원 용지 — `/`에서 등록소(`GAMES`)를
      순회해 카드로 그린다. 지원 용지는 게임마다 다르지 않아(인쇄 규격이 A4로 고정)
      상수로 뒀다
- [x] 게임 상세 페이지 — 소개 · 준비물 · 도안 미리보기 · 만들기 진입 —
      `/games/[id]`. **게임 방법은 본문으로 옮기지 않았다** — 아래 결정 기록 참고
- [x] 메타데이터에서 페이지가 생성되도록 연결 — `generateStaticParams`가
      `gameIds()`를 읽는다. 목록·상세 어느 코드에도 `soccer`라는 이름이 없다
- [x] 기본 레이아웃 · 네비게이션 · 푸터 — `SiteHeader`·`SiteFooter`. 섹션이
      카탈로그 하나뿐이라 내비게이션은 홈 링크 하나다
- [x] 페이지 메타태그와 공유용 이미지 — `generateMetadata`(제목·설명)와
      `opengraph-image.tsx`(루트 · 게임별). 공유 이미지는 글자 없이 그림만
      쓴다 — 이유는 결정 기록

## 수용 기준

- [x] 게임 메타데이터만 추가하면 목록과 상세 페이지가 자동으로 생긴다 —
      `generateStaticParams`·목록 페이지 모두 `gameIds()`/`GAMES`만 읽는다.
      게임을 추가해도 `src/app/` 아래 파일은 고치지 않는다
- [x] 모바일 화면에서 목록과 상세가 깨지지 않는다 — `npm run dev` + 헤드리스
      브라우저로 1280px·390px 두 폭에서 목록·상세·에디터 진입 페이지를 직접
      스크린샷으로 확인했다. 가로 스크롤·글자 겹침 없음
- [x] 상세 페이지에서 에디터로 이동하는 경로가 동작한다 — "만들기 시작" 링크가
      `/games/[id]/edit`로 이동하고 그 라우트가 404 없이 렌더된다. 실제 편집
      기능은 `IDE-006`의 몫이라 이 페이지는 자리표시자다(스크린샷으로 확인)

## 결정 기록

- 2026-09-04 · 썸네일을 새로 그리지 않고 축구 게임판 운동장 아트워크
  (`field.svg`)를 그대로 재사용하기로 했다. `public/games/soccer/README.md`가
  예정해 둔 `thumbnail.png`을 만드는 대신 `assets/games/soccer/index.ts`의
  `thumbnail`을 `artworkPath('field')`로 바꿨다 — 실제로 인쇄될 도안을 보여주는
  게 별도 아이콘보다 정직한 미리보기이고, 새 그림을 만드는 주관적 디자인 작업도
  피할 수 있다.
- 2026-09-04 · **"게임 방법"을 상세 페이지 본문에 옮기지 않기로 했다.** 축구
  게임판의 규칙 텍스트(`src/assets/games/soccer/rules.ts`)는 `GameDefinition`
  스키마에 없는 필드라 카탈로그(게임을 몰라야 하는 코드)가 읽으려면 이 게임
  이름을 하드코딩해야 한다 — 등록소 패턴을 어긴다. 게다가 그 파일 자체에 "인쇄물
  문구가 규칙의 유일한 전달 수단이다"라는 기존 결정(`IDE-004`, 2026-09-03)이
  적혀 있어, 규칙을 웹에도 복제하는 건 그 결정과 어긋난다. 대신 상세 페이지의
  "구성" 목록에 게임 방법 카드(`rules-card` 파트)가 무엇인지는 보이게 했다 —
  전체 규칙이 필요해지면 스키마에 필드를 추가하는 별도 이슈가 먼저다.
- 2026-09-04 · 공유 이미지(`opengraph-image.tsx`, 루트·게임별)에 **제목 글자를
  넣지 않기로 했다.** 사이트 문구가 전부 한글인데 `next/og`의 기본 폰트에는
  한글 글리프가 없고, 완전한 한글 폰트(Noto Sans KR, 4.6MB)는 `ImageResponse`의
  번들 상한(500KB)을 훨씬 넘는다. 카카오톡·트위터 등은 이미지와 별개로
  `og:title`·`og:description`(한글 텍스트) 메타를 그대로 보여주므로, 이미지
  쪽은 그림만 맡기고 글자는 메타 텍스트에 맡겼다. 한글 웹폰트 서브셋을 만드는
  방법은 있지만 이 이슈 범위를 넘어 별도로 다룰 만하다.
- 2026-09-04 · 목록·상세 페이지 렌더링 중 `← {게임명}로 돌아가기`처럼 조사가
