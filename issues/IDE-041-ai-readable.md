## 배경

AI 검색 최적화의 셋째 단계(사용자 결정 2026-09-19, 가 → 나 → 다). 재는 수단
(`IDE-039` 유입 · `IDE-040` 크롤러)이 먼저 섰으니, 이제 **읽히기 좋게** 한다.

시작 전에 운영을 보니 이미 된 것이 많았다 — 사이트맵(게임 · 게임 방법 · 글),
구조화 데이터(`WebSite` · `Game` · `BlogPosting` · `BreadcrumbList`, SEO PR #46),
RSS. 빠진 것은 둘이었다. **AI 에게 주는 안내서**와 **AI 크롤러를 향한 명시**.

## 할 일

- [x] `/llms.txt` — 사이트 요약 · 게임(한 줄 소개 · 인원) · 게임 방법 · 공방 일지 ·
      Optional(전체 내용 · 사이트맵 · RSS). llmstxt.org 제안 형식
- [x] `/llms-full.txt` — 게임마다 소개 · 인원 · 준비물 · **규칙 전문**, 글마다 요약.
      AI 가 화면(편집기 · 인쇄 모달)을 돌리지 않고 답할 수 있게
- [x] 두 파일 모두 **공개된 것만** — 사이트맵과 같은 필터(`openGames` ·
      `publishedPosts`), 1분 재검증
- [x] robots.txt — AI 검색 색인 · 사용자 대신 읽는 봇 10개를 이름으로 열고, 그 칸에도
      `/admin` 등을 똑같이 막는다(이름으로 적은 봇은 `*` 를 무시한다). 목록은 크롤러
      표(`IDE-040`)에서 읽는다
- [x] 테스트 7개 · 로컬 서버에서 두 파일과 robots.txt 를 실제로 받아 확인
- [ ] ⚠︎ 배포 뒤 크롤러 표(`IDE-040`)에 `/llms.txt` 가 읽히는지 — 효과를 재는 자리

## 수용 기준

- [x] `/llms.txt` · `/llms-full.txt` 가 200, `text/plain`
- [x] 오픈 전 게임 · 안 낸 글이 실리지 않는다(부르는 쪽 필터 · 시험)
- [x] robots.txt 에서 AI 검색 크롤러에게도 `/admin` 이 막혀 있다
- [ ] ⚠︎ AI 답변에 이 사이트가 인용된다 — 몇 주에 걸쳐 `IDE-039` 채널 · `IDE-040`
      크롤러 표로 본다

## 결정 기록

- **2026-09-19 — llms.txt 는 표준이 아니다.** 어느 AI 가 읽는지 공식으로 밝힌 곳이
  드물다. 만드는 값이 작아 두되, 효과는 크롤러 표에서 이 경로가 읽히는지로 판단한다.
- **2026-09-19 — 학습용 수집(GPTBot · ClaudeBot · CCBot · Bytespider …)은 건드리지
  않았다.** 지금처럼 `*` 로 열려 있다. 막으면 AI 검색 인용과는 무관하게(인용은 검색
  색인 몫이다) 모델 학습에 쓰이지 않는다 — **주인이 정할 일**이라 사용자에게 알렸다.
- **2026-09-19 — 구조화 데이터를 더 붙이지 않았다.** `HowTo` 는 구글이 2023년에
  리치 결과를 거둬 들였고, 필요한 것(게임 · 글 · 경로)은 이미 있다. 규칙 전문은
  `llms-full.txt` 가 더 곧게 전한다.
- **2026-09-19 — 앞서 사용자에게 "구조화 데이터가 홈에만 있다"고 말한 것은 틀렸다.**
  홈 HTML 만 보고 한 말이었다. 게임 · 글 페이지에는 이미 있다.
