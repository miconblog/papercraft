## 배경

현재 저장소도 CI도 없다. 특히 도안과 인쇄는 회귀가 눈에 잘 안 띄는 영역이다 —
좌표가 조금 어긋나거나 슬롯 하나가 빠져도 화면에서는 멀쩡해 보이고 출력해야 안다.
자동 검사가 없으면 조용히 깨진 채로 배포된다.

## 할 일

- [ ] 테스트 러너 도입과 첫 테스트
- [ ] CI 워크플로 — 린트 · 타입체크 · 테스트를 PR마다 실행
- [ ] 배포 대상 결정과 연결, 프리뷰 배포 활성화
- [ ] 도안 스키마 검증을 CI에서 실행 — 깨진 도안이 머지되지 않게
- [ ] 브랜치 보호와 기여 절차를 README에 기록

## 수용 기준

- [ ] PR을 올리면 린트·타입체크·테스트가 자동 실행되고 실패 시 머지가 막힌다
- [ ] main 머지가 배포로 이어진다
- [ ] 스키마가 깨진 도안을 넣은 PR이 CI에서 실패한다
