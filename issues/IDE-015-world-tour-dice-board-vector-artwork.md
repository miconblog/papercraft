## 배경

세 번째 게임이다. 사용자가 옛 인쇄본 〈세계일주 주사위놀이〉(값 50원, 발행
"Victory 덕도리") 사진을 주며 "이것도 만들 수 있도록" 했다(2026-09-08).

`IDE-011`이 남겨 둔 마지막 칸이 **"칸을 이동하는 주사위판처럼 마커가 자유 좌표가
아닌 것"** 인데, 이 게임이 정확히 그것이다. 축구·야구는 마커를 종이 위 아무 데나
놓았고, 이건 **말이 경로 위 정해진 칸에만** 선다.

원본에서 읽히는 것:

- **가로 포스터. 세계지도 한 장이 판 전체**다. 바다에 고래·돌고래·바다표범,
  뭍에 지역마다 동물과 명소 그림이 얹혀 있다.
- **번호 붙은 동그란 칸 63개**가 붉은 화살표로 이어지고, 칸마다 도시 이름이 있다.
- **특수칸은 색 사각형**으로 경로 옆에 붙는다 — `급행`(노랑) · `쉼 = 한번 쉰다` ·
  `또 = 또 한번 하기` · `다시 = 한국에서 다시` · `후퇴 = 무조건 후퇴`. 범례에
  목적지 번호가 붙는다(`4`·`13` 급행, `41`·`33` 후퇴 식).
- **맨 위 띠가 부속 안내**다. 왼쪽이 〈종이주사위 만들기〉(전개도를 오려 풀칠해
  접는다), 오른쪽이 〈말패〉(얼굴 그림 여섯을 오려 말로 쓴다).
- 아래 가운데 〈세계일주 놀이의 특징〉 — 세계 여러 나라의 도시·문화·특산물·동물을
  익히며 놀아 지리 공부가 된다는 설명문.

### 사용자가 정한 방향 (2026-09-08)

원본을 베끼지 않는다. **실제 세계지도**를 쓰고, **도시 수를 사용자가 고른다**.

- 지도는 그림 지도가 아니라 실제 지형이다.
- 도시 수 프리셋은 **50 · 60 · 70 · 80** 넷.
- 경로는 **서울 출발 → 태평양 → 남아메리카 → 북아메리카 → 북극해 → 유럽 →
  아프리카 → 서남아시아 → 동남아시아 → 오세아니아 → 제주 → 서울 도착**.
- 지도 위에서 도시를 **토글로 켜고 꺼서** 수를 늘리고 줄인다.
- 경로도 추천선을 기본으로 그리되, **간선을 지우거나 두 점을 드래그해 잇는다**.

뒤의 둘(토글·간선 편집)은 에디터와 스키마를 건드리므로 `IDE-016`으로 뗐다.
이 이슈는 **그 둘이 딛고 설 데이터와 도안**까지다.

## 지도

- **출처는 Natural Earth**(퍼블릭 도메인, 저작권 표시 의무 없음)의
  `ne_110m_admin_0_countries`. 인쇄용으로는 110m이면 충분하고, 해안선이 더 필요한
  곳만 50m에서 따온다. 빌드 때 단순화해 커밋하고, 앱은 GeoJSON을 실행 중에 읽지
  않는다 — 다른 게임처럼 SVG가 결과물이다.
- **태평양 중심 투영**(중앙 자오선 150°E 언저리)이다. 원본 인쇄본도 유럽이 왼쪽
  끝, 북아메리카가 오른쪽 끝인 태평양 중심이고, 한국 지도책의 관행이다. 무엇보다
  **서울 → 태평양 → 남아메리카가 끊기지 않아야** 한다 — 0° 중심 지도에서는 이
  첫 구간이 종이 좌우로 갈라진다.
- 투영은 **등장방형(equirectangular)이 아니라 로빈슨 계열**을 검토한다. 등장방형은
  고위도가 크게 늘어나 북극해 구간의 칸이 실제보다 멀어 보인다.

## 도시 풀 — 113개, 프리셋 여섯

프리셋은 **중첩**이다. 50에 든 도시는 60 이상 어디에도 반드시 있다. 도시마다
`rank`를 두고 `rank ≤ N`이 프리셋 N이 된다 — 프리셋마다 목록을 따로 들면
어긋난다. 원본은 `src/assets/games/world-tour/cities.ts`이고 아래 표는 거기서
뽑았다. 처음 넷(50–80)은 사용자가 고른 것이고, 90·100은 "최대 100개까지"
요청(2026-09-08)으로 늘렸다.

**판 크기가 도시 수를 따른다**(같은 날 사용자 제안): 50은 A4 한 장, 60·70은 A3
(A4 두 장), 80 이상은 A2(A4 네 장). 칸·말·글자는 실물 치수 그대로이고 지도만

## 특수칸 다섯

사용자가 원본 범례의 뜻을 확정했다(2026-09-08):

| 칸     | 하는 일                         |
| ------ | ------------------------------- |
| `급행` | 칸 오른쪽 위에 적힌 번호로 간다 |
| `후퇴` | 칸 오른쪽 위에 적힌 번호로 간다 |
| `다시` | 출발지로 간다                   |
| `또`   | 주사위를 한 번 더 던진다        |
| `쉼`   | 한 번 쉰다                      |

**급행과 후퇴는 같은 동작이다** — 둘 다 "적힌 번호로 간다"이고, 앞으로 가느냐
뒤로 가느냐만 다르다. 그러니 데이터는 `이동` 하나로 두고 목적지가 앞이면 급행,
뒤면 후퇴로 **그릴 때 판별한다**. 두 종류로 나눠 두면 노란 칸에 뒷번호를 적는
모순이 데이터에서 만들어질 수 있다.

`다시`의 출발지는 서울이다. 이 판은 서울에서 출발해 서울로 돌아오는 한 바퀴라
"출발지 = 1번 칸"이 흔들리지 않는다.

### 목적지는 번호가 아니라 도시로 적는다

원본은 `41 후퇴`처럼 **칸 번호**로 목적지를 가리킨다. 그런데 도시를 토글로 켜고
끄면 뒤쪽 번호가 전부 밀린다 — 번호로 적은 목적지는 조용히 엉뚱한 칸을 가리키게
된다. 그래서 데이터는 **도시 id**로 적고, 칸 오른쪽 위에 찍히는 숫자는 그 도시가
그 판에서 몇 번째 칸인지 세어 그린다.

토글로 목적지 도시가 꺼지면 그 특수칸도 함께 꺼진다. 이 규칙이 없으면 판이
가리킬 곳 없는 번호를 찍는다.

## 결정 기록

### 2026-09-08 — 판 크기가 도시 수를 따른다

사용자 제안: "도시 갯수가 늘어나면 A4 2장으로 확대하고 더 늘어나면 최대 4장까지
지도 판 크기를 키우면 어떨까?" 이어서 "60개 70개 최대 100개까지 테스트해줘".

- **배율이 아니라 판 자체를 키운다.** 배율은 A4에서 이미 밀려난 배치를 그대로
  키울 뿐이다. 칸(6.6mm)·말(13mm)·이름 글자(2.3mm)는 실물 치수로 두고 지도만
  키우면 같은 유럽 땅에 칸이 들어갈 자리가 두 배·네 배가 된다.
- **단계는 셋** — 50: A4 한 장 · 60·70: A3(A4 두 장) · 80·90·100: A2(A4 네 장).
  A3·A2는 A4의 √2배·2배라 판의 틀(띠·지도)은 A4 도안을 배율만 올린 것이고,
  A4 여러 장으로 나누는 것은 인쇄 파이프라인(`IDE-007`)이 이미 한다. 옛 인쇄본이
  4절(약 39×54cm)이었으니 A2(42×59cm)는 오히려 원본에 가깝다.
- **밀림 실측** (실제 위치에서 칸 중심까지, 최대 / 평균):

  | 도시 수 | A4에 놓으면     | 제 종이에 놓으면 |
  | ------- | --------------- | ---------------- |
  | 50      | 12.6 / 2.8 (A4) | —                |
  | 60      | 18.3 / 3.0      | 11.0 / 1.6 (A3)  |
  | 70      | 15.2 / 3.5      | 12.4 / 1.9 (A3)  |
  | 80      | 16.3 / 3.9      | 5.0 / 1.1 (A2)   |
  | 90      | 22.7 / 5.3      | 6.1 / 1.4 (A2)   |
  | 100     | 29.5 / 6.2      | 6.5 / 1.4 (A2)   |

  가장 많이 밀리는 칸은 늘 파리다(런던·암스테르담과 4mm 안에 있다). 테스트가
  종이별 한계(A4 16 · A3 14 · A2 8mm)와 "제 종이가 A4보다 덜 밀린다"를 지킨다.

- **90·100 프리셋을 위해 풀을 113개로 늘렸다.** 토글 전용이던 21개 중 20개를
  90·100 등급으로 올리고, 새로 12개(부산·하노이·양곤·바르셀로나·뮌헨·코펜하겐·
  하르툼·루안다·덴버·보스턴·메데인·수바)를 토글 전용으로 더했다.
- **특수칸은 열넷 그대로다.** 100개 판에서는 그만큼 드물어진다 — 큰 판에 몇 개를
  더 둘지는 놀아 보고 정한다(⚠︎).
- **도안 정의는 여전히 50개 판(A4)을 가리킨다.** 파트 치수가 도시 수에 따라
  바뀌는 것은 지금 스키마로 표현되지 않으므로 `IDE-016`이 넓힐 것에 "파트 크기도
  선택에 따라 바뀐다"가 더해졌다.

### 2026-09-08 — 규칙 변경 · 제주 삭제 · 지도만 (사용자 요청)

- **특수칸은 넷** — `또`를 없앴다. 급행·후퇴는 **주사위를 다시 굴려 그 수만큼**
  앞·뒤로 간다. 목적지 번호가 없으니 도시를 켜고 꺼도 아무것도 안 밀리고,
  표식은 종류 이름만 찍는다. 옛 `또` 자리(도쿄·뉴욕·파리·싱가포르)는 급행·후퇴·
  쉼으로 바꿔 열넷을 유지했다.
- **제주를 뺐다.** 서울과 함께 적기엔 너무 조밀하다. 서울만 고정이고 등급을
  보정했다(괌 50 · 카라카스 70 · 시애틀 80 · 퍼스 90 · 부산 100). 풀은 112개.
- **지도만 출력** — 틀 슬롯 `board-frame`이 `map`이면 제목·안내 띠 없이 지도만
  낸다. 판 높이가 지도 높이가 된다.
- 도시 목록 편집은 `IDE-016` 2단계다 — 판이 값에서 그때 그려지므로 정적 판은
  썸네일용 기본 판 하나만 남았다.

### 2026-09-08 — 작도

- **판이 프리셋마다 따로 나온다**(`board.svg` = 50, `board-60/70/80/90/100.svg`).
  도안 정의는 50만 가리킨다. 현행 스키마에 "켜고 끈 도시 집합"을 담을 자리가 없어 사용자가
  판 위에서 고르는 일은 `IDE-016`이 잇는다 — 그때 쓰라고 `layoutCities(임의의
도시 목록)`와 `resolveSpecials`를 프리셋과 떼어 두었다.
- **마커 슬롯이 없다.** 말은 놀이 중에 움직이므로 인쇄물이 자리를 기억할 이유가
  없다. `styleSets`·`presets`가 빈 첫 게임이고, 스키마는 고치지 않았다. 사용자가
  고치는 것은 말 여섯의 이름(`text`)과 색(`paint`)뿐이다.
- **말은 텐트형이 아니라 지름 13mm 원판이다.** 세우는 말은 칸 간격 8mm 안에서
  이웃 칸을 가린다. 색 테 + 모양(동그라미·세모·네모·별·하트·마름모)으로 흑백에서도
  갈린다.
- **원본 GeoJSON은 저장소에 두지 않는다.** 이슈에 "저장소에 두되 번들에는 넣지
  않는다"고 적었지만 1.6MB라, 0.1°로 단순화한 243KB `land.json`만 커밋하고
  원본은 `npm run fetch:land`로 다시 받는다. 50m를 고른 이유는 110m에 제주·
  하와이·괌이 없고 한반도가 뭉개지기 때문이다.
- **북극해 구간을 다시 잡았다.** 레이캬비크·누크·이칼루이트는 태평양 중심 지도에서
  대서양 양쪽으로 갈라져 화살표가 종이 끝을 넘는다. 원본처럼 알래스카 → 북극점 →
  무르만스크로 건넌다. 레이캬비크는 유럽 구간으로, 누크·이칼루이트는 뺐다.
- **앵커리지를 50으로 올리고 헬싱키 60 · 괌 70으로 내렸다.** 50개 판에서
  샌프란시스코 → 북극점이 북태평양을 통째로 건너는 화살표였다.
- **유럽 차례를 50개 판 기준으로 잡았다** — 모스크바 → 베를린 → 암스테르담 →
  런던 → 파리 → 로마 → 마드리드. 처음엔 모스크바 → 런던 화살표가 암스테르담·
  베를린을 가로질렀다.
- **사이판을 뺐다**(괌과 2mm). 이 시점의 풀은 101개였다(위 절에서 113개로 늘렸다).
- **칸은 실제 위치에서 밀려난다.** 겹치지 않을 때까지 미는 배치라 A4에 60개를
  놓으면 유럽에서 최대 18mm(파리)였다 — 이것이 판 크기를 키우게 된 계기다. 2.5mm 넘게 밀리면 실제 위치에 점을 찍고 선으로
  잇는다 — 지리 공부가 목적인 판이라 숨기지 않는다. 사람 손으로 다듬은 배치가
  더 예쁠 것이지만 결정적이어야(같은 입력 = 같은 SVG) 하고 `IDE-016`이 임의의
  도시 집합에도 써야 해서 알고리즘으로 두었다.
- **남극 옆 사선.** 극을 감싸는 고리를 닫을 때 틈새를 고리의 시작 경도에 넣어
  지도 안쪽에 선이 그려졌다. 지도 끝 자오선에서 다시 시작하게 돌려 고쳤다
  (`docs/world-tour-artwork.md` 3.2).
