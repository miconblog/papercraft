## 배경

`IDE-028` 결정 기록에 "남은 구멍"으로 적어 둔 것이다(2026-09-10). 미리보기를 새
창으로 바꿔 한 길은 막았지만, 편집 화면의 **「목록으로」 · 사이드 메뉴 ·
새로고침 · 창 닫기**로 떠나도 쓰던 글이 똑같이 날아간다 — 편집기는 쓰던 글을
브라우저에만 들고 있다. 2026-09-19 사용자가 "남은거 다 가자"로 착수를 정했다.

## 수용 기준

- [x] 안 고친 글은 어느 길로 떠나도 묻지 않는다 — 편집기가 뜬 뒤에도
- [x] 제목 · 본문(입력 이벤트 없는 변경 포함)을 고친 뒤 새로고침·창 닫기에 묻는다
- [x] 고친 채 앱 안 링크를 누르면 묻고, 머물기로 하면 화면이 그대로다
- [x] 저장하고 나서 떠나면 묻지 않는다. 저장이 실패했으면 여전히 묻는다
- [x] 미리보기(새 창)는 묻지 않는다
- [ ] ⚠︎ **브라우저 뒤로 가기**(앱 안 이력) — 이 가드는 잡지 않는다. 결정 기록 참고

## 결정 기록

- **2026-09-19 — "바뀜"을 폼 값으로 판정한다.** 편집기가 숨은 칸(`doc`)에 늘
  최신 값을 적어 두므로 한 곳만 보면 된다. 대가로, 고쳤다가 되돌려도(undo)
  편집기가 적는 JSON 모양이 처음 값과 달라 "바뀜"으로 남을 수 있다 — 잘못 묻는
  쪽이라 잃는 것은 없다.
- **2026-09-19 — 저장이 실패하면 기준을 새로 찍지 않는다.** 처음엔 저장 결과가
  바뀔 때마다 찍으려 했는데, 그러면 슬러그 겹침 같은 실패 뒤에 **저장 안 된
  글이 "바뀌지 않음"이 되어** 보호가 풀린다.
- **2026-09-19 — 뒤로 가기(앱 안 이력)는 잡지 않았다.** App Router 에는 옮겨 가기
  전에 막는 공식 훅이 없고, `popstate` 는 이미 주소가 바뀐 뒤에 온다 — 되돌리려면
  이력을 조작해야 해서 다른 화면의 뒤로 가기까지 흔들 수 있다. 문서를 떠나는 뒤로
  가기(다른 사이트에서 왔을 때)는 `beforeunload` 가 잡는다.
