## 1. 배포 (먼저)

- [ ] `main` 이 배포됐는지 — `IDE-035`(퍼널)는 `012` 가 운영 DB 에 이미 있어 배포만
      남았다
- [x] 링크드인 표(`013`) 적용 — **2026-09-19 적용했다** — `npm run db:migrate -- --dry` 로 `013` 한 건만

## 2. 공방 일지 편집 화면 — 데스크톱 (10분)

아무 글이나 하나 연다. **공개 중인 글**이어야 내보내기 칸이 선다.

- [ ] 제목을 한 글자 고치고 **사이드 메뉴**를 누른다 → "저장하지 않은 내용이
      있습니다" 확인 창. 「취소」면 그대로 머문다 (`IDE-036`)
- [ ] 같은 상태에서 **새로고침** → 브라우저의 떠나기 확인 창 (`IDE-036`)
- [ ] 저장한 뒤 사이드 메뉴 → 묻지 않고 옮겨 간다 (`IDE-036`)
- [ ] 본문 사진에 마우스를 올려 **☆ 대표 사진으로** → "대표 사진을 바꿨습니다",
      ☆ 가 ★ 로 (`IDE-028`)
- [ ] 내보내기 칸 · 페이스북 **복사하고 창 열기** → 공유 창이 뜨고, 붙여 넣으면
      문구가 들어간다 (`IDE-034`)
- [ ] 링크드인 **글쓰기 창 열기** → 로그인된 상태에서 **문구가 채워져** 있나.
      비어 있으면 `shareActive` 가 막힌 것 — 「문구 복사」로 붙여 넣으면 된다
      (`IDE-034` 결정 기록에 남긴다)
- [ ] 네이버 블로그 **복사하고 창 열기** → 공유 창에서 「블로그」를 고를 수 있나
      (`IDE-034`)
- [ ] **대표 사진 받기** → 파일로 내려받아지나 (`IDE-034`)

## 5. 링크드인 바로 올리기 (앱 등록, 20분) — `IDE-037`

- [ ] [링크드인 개발자](https://www.linkedin.com/developers/apps) > Create app
      (회사 페이지 연결을 요구한다 — 없으면 개인 이름으로 페이지를 하나 만든다)
- [ ] Products 탭 — **Sign In with LinkedIn using OpenID Connect** ·
      **Share on LinkedIn** 추가
- [ ] Auth 탭 > Authorized redirect URLs —
      `https://www.daddyscraft.com/admin/linkedin/callback`
- [ ] Client ID · Secret 을 배포 환경변수 `LINKEDIN_CLIENT_ID` ·
      `LINKEDIN_CLIENT_SECRET` 에 넣고 다시 배포 (1번의 `013` 이 먼저)
- [ ] 편집 화면 · 링크드인 카드 · **링크드인 연결하기** → 동의 → 돌아와서

- [ ] **링크드인에 바로 올리기** → "올렸습니다 · 링크드인에서 보기". 링크드인에서
      카드(제목 · 설명 · 썸네일)와 해시태그가 눌리는지
- [ ] 같은 글에서 한 번 더 누르면 "이미 올렸습니다" 확인 창
